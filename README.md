A Python program that writes a one-image newspaper front page summing up the world news of Wednesday 25 November 2026 — 40 stories from 9 regions on one page: Shenzhou-24 carrying Pakistan's first astronaut, the Asia chip rout (Kospi −6.16%), Israeli strikes killing 7 in Gaza, Ukraine downing 88 of 112 drones, Germany's revised Q3 GDP, Australia's A$740m treaty with Solomon Islands and its 4.9% inflation jump, US core PCE at +3.3% y/y, and an Iowa lead-azide detonation — to /output/entry.png. The page is typeset programmatically (compose_winners.py + winners_data.py / final_data.py) so every story reads clearly in the single image.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
